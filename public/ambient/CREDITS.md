# Ambient sound credits

Every file in this folder is a short loop cut from a recording released under CC0 1.0 (public domain dedication). Attribution is not required; it is given here anyway.

Each loop is mono, 44.1 kHz, MP3 at 64 kbps, loudness-matched, and has the end crossfaded into the start so it repeats without a seam. The vinyl loop is the source clip followed by a time-reversed copy of itself, to make it longer.
